
# Cloud-Based Bus Ticket Reservation System

## Description
A Python application for searching bus routes and booking bus seats.

## Features
- Search available bus routes
- Book bus seats
- View booking details
- Cancel bookings
- Prevent duplicate seat bookings
- Store booking information using SQLite

## Technologies Used
- Python
- SQLite

## How to Run
Run the task3.py file using Python.

## Project Status
Basic bus ticket reservation prototype completed.
